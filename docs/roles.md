# Roles

## Owner (Customer)
- Registers vehicle
- Selects package
- Views service logs (photos/videos)
- Receives updates

## Admin (MotoVault Operator)
- Manages storage slots
- Assigns vehicles to slots
- Activates subscriptions
- Oversees operations

## Service Staff
- Performs cleaning, idling, rides
- Uploads service logs
- Adds photos/videos
