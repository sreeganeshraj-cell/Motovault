# Features

## Core Features (MVP)

### 1. Vehicle Registration
- Add bike/car details
- Link vehicle to owner

### 2. Storage Slot Management
- Fixed capacity:
  - 15 Cars
  - 15 Motorcycles
- Assign vehicle to available slot
- Track slot availability

### 3. Subscription Packages
Customers choose a care package:

#### Essential Care
- Weekly cleaning
- Engine start and idle (15 mins)
- Weekly photo/video report

#### RoadReady Care
- Weekly water wash
- Engine start
- 25 km road run by authorized rider/driver
- Check insurance, pollution, documents
- Renewal support (extra cost)

#### Concierge Care
- Complete personalized service
- Authorized service center visits
- Scheduled maintenance
- Custom modifications
- Expert consultation

### 4. Service Logs ⭐
- Record every activity
- Upload photos/videos
- Maintain history of services
- Build trust through transparency
